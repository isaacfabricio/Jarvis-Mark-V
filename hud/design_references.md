# Referências de Direção Visual

A interface usa a família tipográfica Orbitron como referência de display futurista. A família está disponível no Google Fonts e é descrita como uma sans-serif geométrica voltada para uso de exibição. O repositório público googlefonts/orbitron-vf documenta a fonte, seus pesos e a licença SIL Open Font License 1.1. A implementação usará a folha pública do Google Fonts no `client/index.html`, sem copiar assets visuais de filmes ou franquias.

Referências consultadas:

- Google Fonts — Orbitron: https://fonts.google.com/specimen/Orbitron
- Google Fonts / GitHub — orbitron-vf: https://github.com/googlefonts/orbitron-vf

Direção visual decidida: HUD original de ficção científica, com fundo navy quase preto, ciano elétrico, dourado âmbar, linhas de grade, painéis translúcidos, scanlines, anéis concêntricos e microanimações CSS. A interface é inspirada no gênero e não reutiliza logos, imagens ou elementos protegidos do filme Homem de Ferro.
